# Exploratory Stockfish strength-setting comparison

Use Stockfish 18 UCI_LimitStrength=true at UCI_Elo 1500, 2000, 2500, following the user's final requested settings. Collection initially started with an additional 1320 setting, but was stopped and that setting excluded before fitting. These are engine parameter values, not measured human Elo or calibrated strengths under this study's node budget. The installed engine exposes 1320–3190. No setting 1000 is simulated or mislabeled.

Re-query all 18,351 already retained states from the original 300-game corpus at each setting, with Threads=1, Hash=64, and 5000 nodes. Clear engine game/hash context between independent positions. Preserve the original state/game split, so every setting sees exactly the same states and candidate sets. This compares decisions on a fixed strong-engine state distribution, not self-play distributions of lower-strength engines. Raw labels are stored for reproducibility because weakened move selection may be stochastic and no exposed random seed is available.

At each setting, fit global (8) and joint contextual (18) models, selecting ridge from 0.0001,0.001,0.01 on validation game-mean likelihood. Bootstrap the selected joint model 100 times using an identical sequence of game resamples across settings. Summarize joint coefficients at the fixed original opening/middlegame/endgame and piece-count reference contexts; do not claim these are independent per-cell fits. Bootstrap uncertainty is conditional on the one saved label realization and selected penalty. Report raw/normalized global and contextual estimates, direct expert-label agreement across settings, predictive diagnostics, and paired differences. Do not use the test set to pick a setting or a favorable value table.
