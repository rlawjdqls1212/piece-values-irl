# Stage-specific relative chess piece values from one-step maximum-entropy IRL

Jungbin Kim — UNIST Department of Engineering  
ORCID: https://orcid.org/0009-0000-4719-1228

This repository accompanies the manuscript *Stage-Specific Relative Chess Piece Values Estimated with One-Step Maximum-Entropy IRL*.

The estimator explains **one-step move choices** using a conditional logit / horizon-one maximum-entropy reward model. Its coefficients are **not intrinsic strategic piece prices**. No new IRL algorithm or playing-strength improvement is claimed.

## Experiments

- Original collection: 300 Stockfish 18 self-play games, 5,000 nodes per engine move, eight exploratory opening plies, maximum 240 plies. After game-level splitting and state deduplication: 10,795 training, 3,624 validation, and 3,932 test positions.
- Stage analysis: opening, middlegame, endgame; pooled contextual summaries and independent fits.
- Remaining-piece count: both colors' pawns and pieces, excluding kings; sparse <=10, intermediate 11–21, dense >=22. Independent IRL fits and 100 paired game-bootstrap draws (300 refits).
- Strength-setting experiment: Stockfish `UCI_LimitStrength=true`, `UCI_Elo` 1500 / 2000 / 2500, queried on the same retained positions. These are engine settings, **not calibrated human Elo** at the fixed node budget. Saved moves are the reproducible labels because weakened move selection may be stochastic.

The extensions are exploratory and reuse the original state population. They are not independent data replications. See the protocol files and manuscript for uncertainty and limitations.

## Contents

- `research/`: collection, fitting, analysis, verification, and manuscript-generation programs.
- `research/paper_jcst/`: self-contained JCS&T LaTeX source and figures.
- `results/`: browsable machine-readable summaries and verification reports.
- `data_and_results.zip`: complete synthetic game histories, retained-position/feature caches, fitted models, bootstrap arrays, and saved strength-setting labels. Extract at repository root to create `research/runs/`.
- `MANIFEST.json`: SHA-256 and byte size for each public file (excluding this manifest).

## Reproduce from archived data

Use Python 3.12 (the recorded environment uses 3.12.10). Create a virtual environment and install dependencies:

```bash
python -m venv .venv
# Activate .venv using your operating system's normal command.
python -m pip install -r research/requirements.txt
python -m zipfile -e data_and_results.zip .
python research/study.py selftest
python research/verify_extension.py
python research/verify_piece_count.py
python research/verify_elo.py
```

To refit from the provided histories and cached features:

```bash
python research/study.py fit --data research/runs/main_data --out research/runs/main_fit --bootstrap 100
python research/stage_analysis.py
python research/extended_irl.py
python research/piece_count_irl.py
python research/elo_irl.py fit --workers 3
python research/elo_irl.py summarize
```

To regenerate demonstrations, download Stockfish 18 separately from https://github.com/official-stockfish/Stockfish/releases/tag/sf_18 and use:

```bash
python research/study.py collect --engine /absolute/path/to/stockfish --out research/runs/new_data --games 300 --seed 10000 --nodes 5000
```

The strength collector's `ENGINE` constant can be changed to the installed executable. It resumes completed labels, so use a new output directory for a new realization. Collecting again may not reproduce stochastic weakened moves exactly. Fitting the archived labels reproduces the reported target dataset.

## Manuscript

Compile `research/paper_jcst/main.tex` with `pdflatex`, `bibtex`, and two further `pdflatex` passes. The source uses the journal's official class and IEEEtran style. It is a manuscript, not a published or accepted article.

Full programmatic rebuilding uses `make_count_section.py`, `make_elo_section.py`, and `make_jcst.py`. Configure the TeX executable directory in the latter for your system. Research scripts have small platform-independent numerical dependencies; the engine executable and TeX installation are separate.
